## Vérification des mises à jour / Update check

`versions.json` est lu par les mods au lancement pour savoir s'il existe une nouvelle version.
Les mods ne téléchargent rien et n'envoient rien : ils lisent seulement ce fichier public et,
s'il y a plus récent, proposent d'ouvrir la page Nexus.

`versions.json` is read by the mods at startup to check for a newer version.
The mods download and send nothing: they only read this public file and, if there is a newer
version, offer to open the Nexus page.

Désactiver / Disable: `UserData/MelonPreferences.cfg`, section `[Mowglie34_MisesAJour]`, `Verifier = false`.
